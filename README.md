Pawsitive Pet Academy is a group project delivering a website and Android mobile application
for client Sarah Smith, founder of a pet care academy. The website is built in HTML, and the mobile app in Kotlin. Both platforms provide course information, inquiry submission,
an automated quote calculator with multi-course discounts, and a consistent brand identity
using the academy's Deep Teal, Soft Teal, Warm Orange, Warm Yellow, Dark Grey and White palette. The 
design follows User-Centred Design principles and all code is version-controlled on GitHub as a group..
